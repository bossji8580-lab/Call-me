# App Download Website Starter

Files:
- index.html — public landing page
- admin.html — demo admin/settings page
- style.css — responsive design
- script.js — public page settings loader
- admin.js — demo settings editor

## APK later
Open Admin, enter your APK's HTTPS URL and save it. The Download APK button will use that URL.

## Important
This starter's admin uses browser localStorage only. It is NOT a secure production admin panel and does not actually upload files.

For a real upload/admin system, connect the form to a backend such as Firebase Storage + Authentication, Supabase Storage + Auth, or your own server. Keep service/admin credentials on the server; never put secret keys in frontend JavaScript.

You can rename the app and replace the preview/logo/screenshots later.
